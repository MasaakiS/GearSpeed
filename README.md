# GearSpeed

ロードバイクのギア速度表ジェネレータ。Web 版として動作します。

## 作成背景

フロントシングル化が普及し、チェーンリングのサイズ選びに迷うことが増えてきました。「このチェーンリングサイズにすると、実際にどんな速度レンジになるのか？」を手軽に確認できるツールが欲しかったことがこのアプリを作った動機です。

フロントシングルでは、フロントギアの歯数一枚でリアカセット全体の速度レンジが決まります。本アプリを使えば、フロントのチェーンリングサイズを変えながらリアカセットとの組み合わせをシミュレーションし、自分のライディングスタイルや用途に最適なセットアップを見つける助けになります。

また、ギア速度表を見ることで、隣り合うギア間の速度差（ギアステップ）が一目でわかります。速度差が小さければクロスレシオ（細かい変速が可能）、大きければワイドレシオ（登坂や高速域に有利）であることが確認でき、カセット選びの指標にもなります。

## デモ（Web 版）
**GitHub Pages:** https://masaakis.github.io/GearSpeed/

ブラウザからアクセスしてすぐに使えます。

## 概要

- フロントギア・リアギア構成・ホイールサイズ・タイヤ幅を入力して、ケイデンスごとの速度を計算し表形式で表示する。
- 速度・ギア比差をカラーグラデーションで視覚化。
- ダークモード自動対応（OS 設定に連動）。
- カセットプリセットのフィルタリング・選択（速度数・カテゴリ・メーカーで絞り込み可能）。
- カスタムギアセットの保存・読み込み（localStorage）。
- 生成した表をクリップボードにコピーして共有。
- オフラインでのキャッシュは標準的なブラウザキャッシュに依存します。

## 主要機能

### Web 版（`docs/`）

1. フロントギア（20〜60T、デフォルト 40T）／ホイールサイズ（700c / 650c）／タイヤ幅（デフォルト 28mm）設定
2. モード選択：**Preset**（カセットプリセットから選択）または **Custom**（手動入力）
3. **カセットプリセット** — 速度数・カテゴリ・メーカーでフィルタリングし、選択するだけでリアギアを自動入力
   - 対応メーカー：Shimano / SRAM / Campagnolo
   - 対応速度数：9s 〜 13s（デフォルト 12s）
4. **カスタムギアセットの保存／読み込み** — ブラウザの localStorage に名前付きで保存・呼び出し
5. "Generate" ボタンで速度表を生成（ケイデンス 70 / 80 / 90 / 100 / 110 rpm）
6. 速度・ギア比差をカラーグラデーションで表示
7. 表をクリップボードにコピー

### Pythonista 版（`gear_speed_backup.py`）

- iPhone/iPad 上の Pythonista 3 で動作するオリジナル版。
- `ui`, `console`, `dialogs`, `clipboard`, `objc_util` などの Pythonista 専用モジュールを使用。
- 現在はバックアップとして保存されています。

## 使い方

### Web 版

1. https://masaakis.github.io/GearSpeed/ をブラウザで開く。
2. モードを「Preset」にして、速度数・カテゴリ・メーカーでプリセットを絞り込み、使用するカセットを選択する。
3. フロントギア・ホイールサイズ・タイヤ幅を必要に応じて変更。
4. 「Generate」をタップ／クリックして速度表を生成。

### Pythonista 版（ローカル実行）

1. Pythonista 3 を起動。
2. `gear_speed_backup.py` を開き、実行ボタンをタップ。
